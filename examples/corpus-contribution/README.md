# Contribute an observation

`ordinary.md` records what happened and what remains uncertain in normal prose.
Prepare a public copy with `vaws-knowledge contribution prepare --kind experience`,
then submit it with `vaws-knowledge contribution submit --kind experience` using
a configured fork checkout. The observation stays in `corpus/experience/`.
Use `--kind knowledge` for a maintained current conclusion in `corpus/knowledge/`.
Use each command's `--help` for paths. Review and merge take place on the PR.
